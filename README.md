# 오늘 뭐 입지 (weather-outfit)

지금 체감온도(Open-Meteo 날씨)에 맞춰 옷차림을 추천하는 휴대폰용 웹앱입니다.

- 열기: https://lsc2016.github.io/weather-outfit/ (또는 `index.html` 을 브라우저로 열기, 빌드 없음)
- 탭 셋: 오늘(추천 · 입은 기록) · 옷장(내 옷 넣기 · 택 찍기 · 내보내기/가져오기) · 나(사이즈 · 메모)
- 내 옷장 · 기록은 그 기기 브라우저(localStorage)에만 저장됩니다. 옮기거나 지키려면 옷장 탭의 "내보내기".
- 시험: `npm test`
